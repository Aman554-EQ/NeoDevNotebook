### Fixed: dev-server issues (commit `fix: clear dev-server issues on every route`)

- **Next.js "URL data outside of `<Suspense>`"** (instant-navigation insight) on all six dynamic pages (`learn`,
  `practice`, `interview` lists and detail pages). The first fix wrapped each page in `<Suspense>` with a skeleton.
  The production check then showed the prerendered HTML starting with that fallback, which caused a layout shift
  (CLS 0.13 at 360 px) and React error #419 on 404 pages. The final fix keeps the pages as they were and adds
  `export const instant = false` (Next's documented "allow a blocking route" option), which is right for fully
  prerendered pages. CLS is back to 0.00.
- **Hydration mismatch** caused by a browser extension (Bitdefender's `bis_skin_checked` / `bis_register`,
  `__processed_*`). A development-only inline script (`ExtensionAttrScript`) strips those attributes before React
  hydrates. Production React doesn't compare attributes, so the script isn't rendered there.
- **`THREE.Clock: This module has been deprecated`** warning on every 3D canvas: raised inside
  `@react-three/fiber` 9.8.2 (latest stable). three's own `setConsoleFunction` hook now drops exactly that message.
