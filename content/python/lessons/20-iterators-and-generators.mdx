## Intuition: a bookmark in a book

An **iterable** is a book. An **iterator** is a **bookmark** in it: it knows where you are and gives
you the next page when asked. When the pages run out, it says so. A **generator** is a function that
keeps its own bookmark. It runs until `yield`, hands over a value, and **pauses** with all its local
variables intact until the next value is requested.

## See it

A recorded run. Watch `countdown` **pause** at each `yield` (its frame leaves the stack) and
**resume** on the very next line when the `for` loop asks for another value.

## The precise rules

- `for x in obj` calls `iter(obj)` once to get an iterator, then calls `next(it)` repeatedly until it
  raises `StopIteration`.
- A function containing `yield` returns a **generator object** when called. Its body runs only as
  `next()` is called.
- `return value` inside a generator ends it. The value travels on `StopIteration.value`.
- `yield from other` delegates: it yields every item of `other`.
- Iterators are **single-use**. An iterable such as a list (or a class whose `__iter__` is a
  generator) gives a fresh iterator each time.

## Worked example

```python title="iteration.py"
import itertools

it = iter([1, 2])
print(next(it), next(it))
try:
    next(it)
except StopIteration:
    print("StopIteration: the loop's signal to stop")


def gen():
    yield 1
    yield 2
    return "done"


g = gen()
print(next(g), next(g))
try:
    next(g)
except StopIteration as stop:
    print("return value:", stop.value)


def chain(*iterables):
    for it in iterables:
        yield from it


print(list(chain([1, 2], "ab")))


def read_numbers(lines):
    for line in lines:
        yield int(line)


def evens(numbers):
    for n in numbers:
        if n % 2 == 0:
            yield n


print(sum(evens(read_numbers(["1", "2", "3", "4"]))))  # a lazy pipeline


class Countdown:
    def __init__(self, start: int) -> None:
        self.start = start

    def __iter__(self):  # a fresh generator every time, so it's reusable
        n = self.start
        while n > 0:
            yield n
            n -= 1


c = Countdown(3)
print(list(c), list(c))
print(list(itertools.islice(itertools.count(10), 3)))  # take 3 from an infinite iterator
```

```text title="Output"
1 2
StopIteration: the loop's signal to stop
1 2
return value: done
[1, 2, 'a', 'b']
6
[3, 2, 1] [3, 2, 1]
[10, 11, 12]
```

What to notice:

- `read_numbers → evens → sum` processes one value at a time, from the first line to the final
  total. With a file of a billion lines, memory use stays flat.
- `Countdown` is **iterable** (it has `__iter__`), not an iterator, so you can loop over it twice. A
  generator object can be looped over only once.
- `itertools.count` is infinite. `islice` takes just what you need, which is only possible because
  everything is lazy.

## Common mistakes

<Callout type="warning" title="Consuming an iterator twice">
  `rows = csv.reader(f)` can be looped over once. A second `for` loop or `len(list(rows))` finds it
  empty. Convert to a list if you need several passes.
</Callout>

- **Calling a generator function and expecting it to run.** `gen()` alone does nothing. You must
  iterate it.
- **`return [..]` in a generator.** It doesn't produce the list for the caller. It ends the
  iteration (the value goes to `StopIteration.value`).
- **Using `next()` without a default** on a possibly empty iterator raises `StopIteration`. Use
  `next(it, None)`.

## Practice

<Reveal
  kind="hint"
  label="Quick check: how do you get the first even number from a huge iterable without scanning it all?"
>
  `next((x for x in numbers if x % 2 == 0), None)`. The generator stops at the first match, and
  `None` is returned if there's none.
</Reveal>

<KeyTakeaways>

- `for` = `iter()` once + `next()` until `StopIteration`.
- `yield` turns a function into a generator that pauses and resumes with its state intact.
- Generators make lazy pipelines, so memory stays flat however big the data is.
- Iterables can be reused. Iterators (including generator objects) are single-use.

</KeyTakeaways>
