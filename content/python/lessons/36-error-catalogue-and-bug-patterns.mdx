## Intuition: a symptom checker

A doctor recognises common symptoms instantly and goes straight to the likely cause. This page is
your symptom checker. Every message below was produced by actually running the code on Python 3.13.

## The catalogue, generated by running real code

```python title="error_catalogue.py"
import json

numbers = [1, 2]


def forever(n):
    return forever(n + 1)


cases = {
    "NameError": lambda: undefined_name,  # noqa: F821
    "TypeError (str + int)": lambda: "age: " + 30,
    "TypeError (not callable)": lambda: numbers(0),
    "TypeError (missing arg)": lambda: divmod(7),
    "AttributeError": lambda: numbers.push(3),
    "AttributeError (None)": lambda: None.upper(),
    "KeyError": lambda: {"a": 1}["b"],
    "IndexError": lambda: numbers[2],
    "ValueError (int)": lambda: int("3.5"),
    "ValueError (unpack)": lambda: [(a, b) for a, b in ["xyz"]],
    "ZeroDivisionError": lambda: 1 % 0,
    "ModuleNotFoundError": lambda: __import__("reqeusts"),
    "FileNotFoundError": lambda: open("no_such_file.txt", encoding="utf-8"),
    "RecursionError": lambda: forever(0),
    "JSONDecodeError": lambda: json.loads("{'single': 'quotes'}"),
}

for label, trigger in cases.items():
    try:
        trigger()
    except Exception as err:
        print(f"{label:26} {type(err).__name__}: {err}")

broken_sources = {
    "SyntaxError (bracket)": "x = (1, 2",
    "SyntaxError (colon)": "if True\n    pass",
    "IndentationError": "def f():\nreturn 1",
}
for label, source in broken_sources.items():
    try:
        compile(source, "snippet.py", "exec")
    except SyntaxError as err:  # IndentationError is a subclass of SyntaxError
        print(f"{label:26} {type(err).__name__}: {err.msg}")
```

## What each one usually means

| Error                              | Usual cause                                                                         | Usual fix                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `NameError`                        | typo, used before assignment, or missing import                                     | check spelling and imports; define before use          |
| `TypeError: can only concatenate`  | mixing `str` and `int`                                                              | convert explicitly: `str(n)`, `int(s)`, or an f-string |
| `TypeError: … not callable`        | `()` after something that isn't a function; shadowed a built-in (`list = …`)        | remove the call, or rename the variable                |
| `TypeError: … arguments`           | wrong number or kind of arguments                                                   | read the signature (`help(func)`)                      |
| `AttributeError: 'NoneType' …`     | a function returned `None` (often a missing `return`, or `list.sort()`)             | find where the `None` came from                        |
| `AttributeError` (other)           | wrong type or typo; for a near-miss name the traceback often adds "Did you mean …?" | check `type(obj)` and `dir(obj)`                       |
| `KeyError`                         | missing dict key                                                                    | `d.get(k, default)`, `in`, `defaultdict`               |
| `IndexError`                       | off-by-one, or an empty list                                                        | check lengths; loop over items, not indexes            |
| `ValueError`                       | right type, bad value (`int("3.5")`), unpacking mismatch                            | validate or convert carefully                          |
| `ZeroDivisionError`                | dividing by a zero count or length                                                  | guard empty inputs                                     |
| `ModuleNotFoundError`              | typo, not installed, or the wrong environment                                       | `python -m pip install …`; check `sys.executable`      |
| `FileNotFoundError`                | wrong relative path / current folder                                                | build paths with `Path(__file__).parent / …`           |
| `RecursionError`                   | missing or unreachable base case                                                    | fix the base case, or use a loop                       |
| `JSONDecodeError`                  | not valid JSON (single quotes, trailing commas)                                     | fix the producer; JSON requires double quotes          |
| `SyntaxError` / `IndentationError` | unclosed bracket, missing `:`, wrong indentation                                    | look at the marked line **and the line before it**     |

## Silent bugs: no error, wrong answer

<Callout type="warning" title="These don't crash, so tests are your only defence">
  The most expensive bugs produce plausible but wrong results. Each pattern below is covered in its
  own lesson. Write a test that pins the expected output.
</Callout>

- **Aliasing:** `b = a` and then mutating `b` changes `a`. **Mutable defaults:** `def f(x=[])`
  shares one list (lesson 10).
- **Late binding:** `[lambda: i for i in range(3)]` all return 2 (lesson 8).
- **Off-by-one:** `range(1, len(xs))` skips the first item, and `xs[1:]` drops it (lessons 6 and 35).
- **Float equality:** `0.1 + 0.2 == 0.3` is `False` (lesson 3).
- **`sort()` returns `None`:** `xs = xs.sort()` (lesson 11).
- **Integer division surprise:** `-7 // 2 == -4` (lesson 3).
- **Modifying a collection while iterating** skips items or raises `RuntimeError` (lessons 6 and 13).
- **`is` instead of `==`** for values (lesson 2).

## Common mistakes

- **Catching everything** (`except Exception: pass`) turns loud errors into silent bugs.
- **Fixing the symptom** (wrapping in `try`) instead of the cause (where the bad value came from).
- **Not reading the whole message.** It usually names the exact type, key or argument.

## Practice

<Reveal
  kind="hint"
  label="Quick check: AttributeError: 'NoneType' object has no attribute 'append', on line 'result.append(x)'. Likely cause?"
>
  `result` is `None`. Often an earlier line was `result = result.append(y)`, or `result =
  some_list.sort()`. Both methods return `None`. Remove the assignment.
</Reveal>

<KeyTakeaways>

- The exception type plus its message usually names the problem exactly.
- `NoneType` errors mean something returned `None`, so trace where it came from.
- `ModuleNotFoundError` for an installed package means the wrong environment.
- Silent bugs (aliasing, late binding, off-by-one, float `==`) need tests, not try/except.

</KeyTakeaways>
